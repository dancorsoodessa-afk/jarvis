# BOTok Android

Самостоятельное Android-приложение для мониторинга публичного рынка OKX и Paper Trading. Проект расположен в отдельном каталоге `botok/` и не зависит от Windows-приложения Jarvis.

## Что входит в первый APK

- Публичные данные OKX без API-ключей: Spot и USDT Swap.
- Загрузка списка инструментов и поиск по всем доступным инструментам выбранного рынка.
- Live ticker, стакан books5 и лента сделок через публичный WebSocket OKX.
- График live-цены, оценка LONG/SHORT в процентах, RSI и EMA.
- Ручной ввод капитала, риск на сделку и плечо.
- Автоматический расчёт входа, Stop Loss, TP1 и TP2.
- Режим подтверждения перед открытием виртуальной сделки.
- Paper-позиция с контролем SL/TP; реальные ордера не отправляются.

## Ограничения первой версии

Вероятности LONG/SHORT — эвристическая оценка на основе цены, EMA/RSI, дисбаланса первых пяти уровней стакана и потока сделок. Это не обученная прогнозная модель и не вероятность гарантированного результата. Для реальной торговли нужны отдельный аудит, тестирование исполнения, комиссий, проскальзывания и ликвидации. В этой версии нет хранения ключей OKX и нет отправки реальных ордеров.

## Сборка APK

GitHub Actions workflow: `.github/workflows/botok-android.yml`.

Workflow запускается при изменениях в `botok/**` на ветке `BOTok`, а также вручную через GitHub Actions. После успешной проверки APK публикуется как artifact `BOTok-android-apk`.

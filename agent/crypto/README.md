# JARVIS Crypto Analyst — 11 инструментов

Адаптация Trader Skill под криптовалютный рынок и публичные API OKX.

| № | Инструмент | Функция |
|---:|---|---|
| 1 | Copycat / Wallet Watch | Мониторинг публичного BTC-адреса через Blockstream; не определяет личность и не видит полный портфель |
| 2 | News Monitor | Публичная RSS-лента CoinDesk с фильтрацией по тикерам |
| 3 | Budget Manager | Резерв наличности и лимит размера позиции |
| 4 | Whale Watch | Контроль публичного BTC-адреса |
| 5 | Market Analyst | Тикер, 24-часовое изменение, диапазон и объём OKX |
| 6 | Crypto Screener | Рейтинг спотовых USDT-пар OKX по изменению и объёму |
| 7 | Risk Manager | Размер позиции от заданного риска, без плеча |
| 8 | Paper Broker | Запись виртуальной заявки в `data/crypto/paper_orders.json` |
| 9 | Tax Lots | FIFO-учёт себестоимости и реализованного PnL |
| 10 | Price Alerts | Проверка порогов цены |
| 11 | Rebalancer | Расчёт отклонений от целевых долей портфеля |

## Безопасность и ограничения

- Только публичные рыночные данные. API-ключи OKX не нужны.
- Реальное выставление ордеров отсутствует в коде. Broker создаёт только `PAPER_PENDING` запись.
- News и Whale Watch используют внешние публичные источники; доступность источников зависит от сети.
- Tax Lots — арифметический FIFO-расчёт, не налоговая консультация.
- Copycat/Whale Watch мониторит только публичный BTC-адрес; это не копирование реального портфеля.
- Это Python-пакет. Подключение к runtime-регистратору инструментов и экрану меню Windows ещё отдельный этап; этот коммит не заявляет, что UI уже подключён.
